# 🍽️ Building Responsive Website

## 📖 Description

Building Responsive Website is a modern and responsive restaurant website developed using HTML, CSS, JavaScript, and Bootstrap. The project is designed to provide an attractive and user-friendly interface that adapts seamlessly to desktops, tablets, and mobile devices. It showcases various restaurant services, menu items, online ordering, payment options, and multimedia content while following responsive web design principles.

---

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Modern and attractive user interface
- Smooth navigation bar
- Home page with banner section
- Why Choose Us section
- Explore Menu section
- Healthy Food section
- Delivery & Payment section
- Customer Testimonials section
- Follow Us section
- Footer section
- View Menu page
- Online Order page
- Payment page
- Watch Video page
- Bootstrap components for responsive layouts
- Clean and organized project structure

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open **index.html** in any modern web browser.
4. Explore the different pages using the navigation menu.
